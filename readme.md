# Tutor di Fisica 1 - Streamlit

App Streamlit per un tutor virtuale socratico di Fisica Generale 1.

## Funzionalità MVP

- chat tutor con guida socratica
- mappa argomenti
- diagnostica prerequisiti
- esercizi guidati
- profilo studente in sessione

## Struttura progetto

- `app.py`: homepage
- `pages/`: pagine Streamlit
- `core/`: logica applicativa
- `content/`: contenuti del corso

## Avvio locale

```bash
pip install -r requirements.txt
streamlit run app.py
